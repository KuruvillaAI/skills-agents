# Pull Request Checklist

- [ ] Branch follows naming convention (`feature/`, `fix/`, `chore/`, `security/`)
- [ ] Commits follow conventional commit format
- [ ] PR description states affected repositories/features and links related issues
- [ ] All required automated tests pass in CI
- [ ] Definition of Done checklist completed
- [ ] Security checklist completed (if applicable)
- [ ] QA sign-off checklist completed (if UI/workflow affected)
- [ ] No unresolved review comments
